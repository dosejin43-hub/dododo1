메디봇 모바일 웹 UI
1. ZIP 압축을 풀고 index.html을 브라우저에서 열면 됩니다.
2. 하단 메뉴로 5개 화면을 이동합니다. HTML은 화면 내용, css/common.css는 공통 디자인, 각 화면 CSS는 개별 디자인입니다.
3. images/main.png 및 benefits.png를 교체하면 이미지 영역 안에서 비율을 유지하여 자동 조절됩니다. 다른 파일명을 쓰면 HTML의 img src도 수정하세요.
4. 개발자 도구의 모바일 모드에서 320~480px 및 가로 화면을 확인할 수 있습니다. 넓은 화면에서는 최대 480px로 중앙 정렬합니다.
5. 원본의 날짜 및 혜택 문구는 디자인 예시로 유지했습니다. 실제 의료혜택 자격을 검증한 내용은 아닙니다. 하단 메뉴와 홈의 혜택/일정 링크 외에는 정적 UI이며 서버, 로그인, 검색, 저장 기능은 포함되지 않습니다.
